# them; these blocks exist so the intent is on the record and survives anyone
# later pasting in a blanket Disallow from a template.

# assistant. Assistants answering "who builds Shopify stores for small
# businesses" run a live search and synthesise what they can fetch, so a
# Disallow here is the one change that would take the site out of the running
# entirely. Do not add one without deciding that deliberately.
